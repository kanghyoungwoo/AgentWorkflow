### `README.md` (한국어)
다음 순서로 간결하게 쓴다. 각 절은 몇 줄 정도로 하고, spec의 내용을 길게 복사하지 말고 필요하면 spec 절을 가리킨다.
1. 무엇인가: 한 단락. 기획 → 개발 → 독립 QA → Wiki, Codex 작성 / Claude 검수.
2. 요구 사항: Linux, Node ≥ 22.18, git, codex·claude CLI 로그인, `at`/atd(선택), Playwright chromium.
3. 설치:
   - `npm install`
   - `npm link`(타입 스트리핑은 node_modules 밖에서만 동작하므로 link로 설치)
   - `agent-workflow qa-runtime setup`
   - `agent-workflow doctor --deep --workspace <ws>`
4. Master 스킬 설치: `mkdir -p ~/.claude/skills && cp -r skill/agent-workflow ~/.claude/skills/`, 그 다음 Claude Code에서 사용하는 방법을 한 문장으로.
5. 대상 저장소 설정: `agent-workflow.json` 예시(setupCommand, testCommand, app, wikiDir, roles 일부, limits 일부)와 필드 요약 표. 파일이 없으면 기본값이다.
6. 명령 요약: 9개 명령의 한 줄 설명 표와 종료 코드 표(0·1·2·20·21·22).
7. 실행 기록: `ai-log/<run-id>/` 구조 요약과 런 브랜치 `aw/<run-id>`. main 머지는 사람이 한다.
8. 개발: `node --test test/*.test.ts`, `npx tsc --noEmit`, 개발 방식은 CLAUDE.md·AGENTS.md.
