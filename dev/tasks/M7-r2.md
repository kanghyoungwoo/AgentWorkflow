# M7-r2 작업 지시서 — 예약과 조회 명령 (2라운드)

## 목표
M7-r1 결과물을 검수 지적에 맞게 고친다. 범위·spec 절·공통 규칙은 `dev/tasks/M7-r1.md`와 같다. 검수 전문은 `dev/reviews/M7-r1.md`. spec.md는 수정하지 않는다.

## 고칠 지적

### R-001 — resume은 검증이 모두 통과한 뒤에 예약을 해제한다
- 지금은 인자·Pending 검증 전에 `cancelResume`을 호출한다. 그래서 잘못된 `--lane`이나 `--answer`로 종료 코드 2가 나도 at 예약이 사라진다.
- 모든 검증(run-id, lock, `--mode`, `--answer`·`--grant`·`--lane` 선택)이 끝나고 실제로 재개하기로 정해진 뒤에 예약을 해제하고 `scheduledResume`을 null로 한다.
- 테스트: 예약이 있는 런에 잘못된 `--lane`으로 resume하면 종료 코드 2이고, cancel이 호출되지 않으며 scheduledResume이 그대로인지 확인한다. 올바른 resume에서는 cancel이 호출되는지도 확인한다.

### R-002 — `listStates`는 run-id 형식이 아닌 항목을 건너뛴다
- `ai-log/` 아래 형식이 맞지 않는 디렉터리나 파일이 있어도 `list`와 `cleanup --finished`가 실패하지 않게 한다.
- 테스트: `ai-log/notes.txt`와 `ai-log/bad dir/`가 있어도 list가 정상 런만 보여 주는지 확인한다.
