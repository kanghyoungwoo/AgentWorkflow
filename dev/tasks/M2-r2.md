## 고칠 지적

### R-001 — 실패 원인 보존
- `src/clients/claude.ts`: 실행 예외를 잡을 때 원래 메시지를 `error`에 포함한다. 예: `Claude 프로세스를 실행할 수 없습니다: <message>`.
- `src/commands/doctor.ts`: V3·V4가 fail이면 detail에 그 호출의 `error`와 `exitCode`를 붙인다.
- 테스트: 위 두 경우를 각각 확인한다.

### R-002 — `V4 git diff` 검사를 분리하고 토큰으로 판정
- V4 쓰기 검사는 쓰기만 지시한다. 스키마는 `{ ok: boolean }`이고, 파일 존재·status·HEAD로 판정하는 지금 방식을 유지한다.
- git diff 검사는 별도 호출로 한다.
  - 준비: 임시 저장소에 무작위 토큰(`randomUUID()`)이 든 파일을 커밋하고, 작업 사본에서 그 줄을 지운다. 토큰은 `git diff`의 `-` 줄에만 남는다.
  - 호출: readonly 프로필, 스키마 `{ token: string }`(additionalProperties false, required).
  - 프롬프트: "Run `git diff HEAD` with the Bash tool and return the text of the removed line as token."
  - 판정: token이 일치하면 `V4 git diff` ok, 아니면 warn("readonly 프로필에서 git diff 결과를 확인하지 못함" + 받은 값이나 error).
- 테스트를 새 방식에 맞게 고친다. 가짜 클라이언트로 토큰을 맞게 돌려주면 ok, 틀리면 warn.

### R-003 — playwright 지연 로드
- `src/commands/doctor.ts`의 최상위 `import { chromium } from 'playwright'`를 없앤다. 기본 `launchBrowser` 안에서 `await import('playwright')`로 불러온다.
